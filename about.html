关于本站

由玩家原创整理的《钢铁之泪》中英双语攻略站——持续更新。

我们的使命

为中文玩家提供最全面、最准确、最易用的《钢铁之泪》攻略。帮助你更快掌握游戏，再也不需要其他攻略站。

中英双语

完整的中英双语支持。所有内容都有中英文两个版本。随时切换——偏好自动保存。

进度追踪

追踪神器、徽章、护符、环境、Boss、Meta 升级和图鉴的收集进度。支持设备间导出/导入。全部本地存储——无需注册。

离线访问

本站是 PWA（渐进式 Web 应用）。首次访问后可离线使用。添加到主屏幕即可获得类原生应用体验。

智能搜索

用中文或英文关键词搜索全站内容。覆盖页面、神器、徽章、护符、环境、Boss 和具体章节。

持续更新

我们跟踪游戏更新并定期核实数据。查看更新日志了解更新历史和数据核实日期。

技术栈

前端

  • 纯 HTML5 + CSS3 + 原生 JavaScript
  • 无框架依赖，零构建步骤
  • IIFE 架构，window.TM_ 全局 API

功能

  • CSS 变量实现暗色模式主题
  • localStorage 存储语言、主题、进度
  • Service Worker + manifest.json 实现 PWA
  • 客户端搜索索引（无需服务器）

SEO 与性能

  • Meta 标签、JSON-LD、Open Graph、Twitter Cards
  • sitemap.xml + robots.txt
  • 链接预加载实现即时页面切换
  • SVG sprite 实现轻量图标
